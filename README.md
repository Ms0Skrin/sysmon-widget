# sysmon-widget

Полупрозрачный виджет для рабочего стола Windows 10/11 и Linux (Wayland): монитор системы, панель
быстрого запуска, темы, датчики LibreHardwareMonitor и интеграция NabyScape.

## Возможности

- **Плитки мониторинга**: ЦП (нагрузка, потоки, температура), память, ГП NVIDIA (нагрузка,
  температура, видеопамять, мощность), диск, сеть — и **любые датчики LibreHardwareMonitor**
  (температуры ядер, вентиляторы, частоты, напряжения, NVMe…) — каждый можно включить отдельной плиткой
  в *Настройки → Датчики*. Раскладка 1–4 колонки.
- **Темы**: Windows (родная — системный акцент и светлый/тёмный режим), Графит, Полночь, Светлая, Неон,
  Терминал, Закат + стили графиков (область, линия, столбцы, ступеньки). Живые превью в настройках.
- **Панель приложений** — кнопка с точками или глобальная горячая клавиша (по умолчанию `Ctrl+Alt+Space`).
  Анимированно вылетает в центр экрана, сетка подстраивается под количество приложений,
  полупрозрачность настраивается. `1–9` — запуск, набор текста — поиск, `Enter` — первое найденное.
- **Сканер установленных приложений** (всё из меню «Пуск», включая Магазин) + добавление любого exe/ярлыка.
- **Чистый рабочий стол**: скрытие иконок, эффекты прозрачности Windows (меню «Пуск»), прозрачная панель
  задач через TranslucentTB (прозрачная / размытие / акрил / цвет темы).
- **NabyScape** — «остров» с музыкой, текстами песен, таймерами, заметками и ИИ: включается одной галочкой,
  виджет сам скачивает официальную сборку и управляет ею; пункты появляются в меню и трее.
- Перетаскивание и закрепление виджета, прозрачность, «поверх всех окон», автозапуск.
- **Трей** (ПКМ): показать/скрыть, приложения, настройки, NabyScape, проверить обновления, выход.
- **Обновление** через `git pull` прямо из трея.

## Установка

```powershell
git clone https://github.com/Ms0Skrin/sysmon-widget.git
cd sysmon-widget
python -m pip install --user -r requirements.txt
pythonw widget.py
```

Нужен Python 3.10+. При первом запуске виджет предложит один раз подтвердить права администратора
(UAC) для датчиков: поставит драйвер PawnIO (если нет) и задачу Планировщика, чтобы дальше датчики
запускались без запросов. Всё это переключается в *Настройки → Датчики*.

## Linux (Wayland)

Тот же виджет работает на Linux — в композиторах с протоколом layer-shell: **niri, Hyprland, Sway,
KDE Plasma, COSMIC** и других (в GNOME протокола нет). Окна сделаны на GTK4, отрисовка плиток, темы
и настройки — общие с Windows-версией.

```sh
# Arch / CachyOS (для других систем скрипт сам подскажет пакеты)
sudo pacman -S --needed gtk4 gtk4-layer-shell python-gobject python-psutil python-pillow
git clone https://github.com/Ms0Skrin/sysmon-widget.git
cd sysmon-widget
./install-linux.sh --autostart      # команда sysmon-widget, ярлык в меню, запуск при входе
sysmon-widget
```

- **Панели** лежат на рабочем столе под окнами (или над ними — «Поверх всех окон»), двигаются мышью,
  липнут к краям и друг к другу, переезжают на соседний монитор, если утащить за край.
- **Датчики** читаются без прав администратора: температуры и вентиляторы из hwmon (процессор,
  NVMe/SATA, материнская плата), частоты ядер, видеокарты NVIDIA (`nvidia-smi`) и AMD. Любой датчик
  можно вывести отдельной плиткой: *Настройки → Плитки и датчики*.
- **Панель приложений**: кнопка с точками, значок в трее или команда `sysmon-widget --launcher`.
  Глобальные горячие клавиши в Wayland назначает композитор, например в niri:
  `binds { Ctrl+Alt+Space { spawn "sysmon-widget" "--launcher"; } }`.
  Показывает закреплённые приложения (ПКМ по значку — закрепить), поиск идёт по всем установленным.
- **Трей** (StatusNotifierItem): ЛКМ — показать/скрыть панели, ПКМ — меню.
- Команды работающему виджету: `--launcher`, `--settings`, `--toggle`, `--show`, `--hide`, `--quit`.
- Тема «Системная» берёт цвета рабочего стола (палитра matugen/Ryoku), если они есть.
- Настройки: `~/.config/sysmon-widget/config.json`. Удаление: `./install-linux.sh --remove`.

Только для Windows остались: скрытие иконок рабочего стола, прозрачная панель задач (TranslucentTB),
NabyScape и вид панели приложений «Соты».

## Как устроены права

Сам виджет работает **без** прав администратора (иначе всё, что запускается из панели приложений,
тоже стартовало бы с правами админа). Датчики читает отдельный маленький процесс `sensor_host.py`
с правами администратора — он загружает встроенный `LibreHardwareMonitorLib` и пишет показания в
`%APPDATA%\sysmon-widget\sensors.json`, а когда виджет закрыт — завершается сам.

## Настройки

`%APPDATA%\sysmon-widget\config.json`

## Сторонние компоненты

| Компонент | Лицензия | Как используется |
|---|---|---|
| [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) | MPL-2.0 | библиотеки в `vendor/lhm` |
| [PawnIO](https://github.com/namazso/PawnIO) | — | драйвер, ставится через winget по согласию |
| [NabyScape](https://github.com/BillyNabil/nabyscape) | MIT | скачивается с GitHub Releases при включении |
| [TranslucentTB](https://github.com/TranslucentTB/TranslucentTB) | GPL-3.0 | скачивается с GitHub Releases при включении |

## Структура

| Файл | Что делает |
|---|---|
| `widget.py` | точка входа, окно виджета, плитки, меню, трей |
| `launcher.py` | панель приложений с анимацией |
| `appscan.py` | поиск установленных приложений |
| `settings.py` | окно настроек (вкладки) |
| `theme.py` | темы, стили графиков |
| `sensors.py` / `sensor_host.py` / `sensorsvc.py` | датчики: чтение / процесс с правами / управление |
| `nabyscape.py` | интеграция NabyScape |
| `translucenttb.py`, `winstyle.py` | панель задач, прозрачность Windows |
| `hotkey.py`, `desktop.py`, `icons.py` | горячая клавиша, иконки рабочего стола, иконки программ |
| `updater.py`, `config.py` | обновления, настройки, автозапуск |
| `linux/` | Linux-версия: окна GTK4 + layer-shell (`app.py`, `panel.py`, `launcher.py`, `settings.py`, `menu.py`), датчики (`sensors.py`), трей (`tray.py`) |
| `install-linux.sh` | установка в домашнюю папку на Linux |
