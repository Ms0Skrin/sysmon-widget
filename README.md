# sysmon-widget

Полупрозрачный виджет для рабочего стола Windows 10/11: монитор системы + панель быстрого запуска приложений.

## Возможности

- **Плитки мониторинга** (включаются в меню «Плитки», раскладка 1–3 колонки):
  нагрузка ЦП и по потокам, температура ЦП, память, нагрузка / температура / видеопамять / мощность ГП (NVIDIA), диск, сеть.
- **Перетаскивание** мышью и **закрепление** на месте (🔒).
- **Панель приложений** — кнопка ⊞ на виджете или глобальная горячая клавиша (по умолчанию `Ctrl+Alt+Space`, меняется в настройках).
  Добавляй свои программы/ярлыки, `1–9` — быстрый запуск, ПКМ по плитке — переименовать, сдвинуть, удалить.
- **Скрытие иконок рабочего стола** — чистый стол, всё запускается из панели.
- **Иконка в трее** (ПКМ): показать/скрыть, приложения, настройки, проверить обновления, выход.
- Обновление через `git pull` прямо из трея, автозапуск с Windows, прозрачность, «поверх всех окон».

## Установка

```powershell
git clone https://github.com/Ms0Skrin/sysmon-widget.git
cd sysmon-widget
python -m pip install --user -r requirements.txt
pythonw widget.py
```

Нужен Python 3.10+.

## Температура процессора

Windows не отдаёт температуру ЦП без драйвера. Запусти
[LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/releases) от администратора
(можно свернуть в трей) — виджет подхватит его датчики через WMI.
Температура видеокарты NVIDIA берётся из `nvidia-smi` и работает сразу.

## Настройки

Хранятся в `%APPDATA%\sysmon-widget\config.json`.

## Структура

| Файл | Что делает |
|---|---|
| `widget.py` | точка входа, окно виджета, плитки, трей |
| `launcher.py` | панель приложений |
| `settings.py` | окно настроек (горячая клавиша и пр.) |
| `hotkey.py` | глобальная горячая клавиша (RegisterHotKey) |
| `desktop.py` | показ/скрытие иконок рабочего стола |
| `icons.py` | извлечение иконок программ |
| `sensors.py` | nvidia-smi и LibreHardwareMonitor в фоне |
| `updater.py` | проверка и установка обновлений через git |
| `config.py`, `theme.py` | настройки, автозапуск, цвета |
